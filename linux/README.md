# 리눅스 입문 노트

리눅스 입문 강의(1–22강, 15강 제외)를 정리하고 강의마다 셀프 체크 문제를 붙인 학습 노트입니다. 파일 하나(`index.html`)로 동작하며 브라우저에서 열면 됩니다.

- **강의 노트**: 강의별 핵심 요약(SYNOPSIS), 표·코드로 정리한 본문, 정답을 펼쳐 보는 셀프 체크
- **명령어 치트시트**: 강의에서 다룬 명령어·기호를 분류별로 모아 검색, 강의 노트로 바로 이동
- **검색**: `/` 키로 검색창 열기, 노트와 치트시트를 함께 필터링
- **진도 체크**: 목차 체크박스로 강의별 완료 표시. 기록은 브라우저(localStorage)에만 저장됩니다.

다루는 범위: 리눅스 개념·셸·배포판 → VirtualBox로 Ubuntu·Rocky Linux 설치 → 기본 명령어·파일시스템·경로·cp/mv → nano·vi·문자 처리·리다이렉션·파이프 → 셸 변수·환경 변수·셸 스크립트(위치 매개변수, 입출력, 조건문, 반복문) → tar·gzip·zip 압축.

참고한 강의: ToyMakers, 「리눅스 입문」 (YouTube). 내용은 강의를 듣고 직접 정리한 것이며 강의 화면이나 자료 파일은 포함하지 않습니다. 그림은 모두 HTML/CSS로 새로 그렸습니다.

글꼴은 Google Fonts에서 불러오므로 인터넷 연결이 없으면 시스템 글꼴로 표시됩니다.
