# 리눅스 입문 노트

리눅스 입문 강의(1–22강, 15강 제외)를 정리한 학습 노트입니다. 데이터베이스 문제집과 같은 형식으로, 강의 한 장씩 넘겨 봅니다. 파일 하나(`index.html`)로 동작하며 브라우저에서 열면 됩니다.

- **강의 노트**: 강의별 핵심 요약, 표·코드로 정리한 본문. `강의 외 보충`과 `노트 정정` 표시로 원래 강의 내용과 구분
- **명령어 치트시트**: 강의에서 다룬 명령어·기호를 분류별로 모아 검색, 강의 노트로 바로 이동
- **진도**: 읽은 강의는 목록에 "읽음"으로 표시됩니다. 기록은 브라우저(localStorage)에만 저장됩니다.
- `←` `→` 키로 이전·다음 강의로 넘어갑니다.

다루는 범위: 리눅스 개념·셸·배포판 → VirtualBox로 Ubuntu·Rocky Linux 설치 → 기본 명령어·파일시스템·경로·cp/mv → nano·vi·문자 처리·리다이렉션·파이프 → 셸 변수·환경 변수·셸 스크립트(위치 매개변수, 입출력, 조건문, 반복문) → tar·gzip·zip 압축.

참고한 강의: ToyMakers, 「리눅스 입문」 (YouTube). 내용은 강의를 듣고 직접 정리한 것이며 강의 화면이나 자료 파일은 포함하지 않습니다. 그림은 모두 HTML/CSS로 새로 그렸습니다.

## 공부 가이드

[`study-guide.html`](study-guide.html)은 같은 강의를 1–34강(15강 제외)까지 정리한 공부용 페이지입니다. [웹에서 열기](https://sang-min-le-e.github.io/cs-study/linux/study-guide.html)

- **큰 틀**: 전체 흐름, 헷갈리는 대비 쌍, 강의 사이의 연결을 한 장으로 정리
- **암기 시트**: 문장 속 빈칸, 연결하기, 순서 맞추기. 강의마다 읽기·외우기 모드로 봅니다.
- **시각화**: 경로 탐색기, 리다이렉션 흐름, vi 모드 전환, 반복문 단계 실행, 와일드카드 테스터, 디스크 3단계, 허가권 계산기, find 시뮬레이터, 서브넷 계산기
- **표시**: `💡`는 노트에 없는 해설, `⚠️`는 노트 내용을 바로잡은 부분입니다.
- **기록**: 체크리스트와 암기 진행 상황은 브라우저에만 저장됩니다.

글꼴은 Google Fonts에서 불러오므로 인터넷 연결이 없으면 시스템 글꼴로 표시됩니다.
