# 데이터베이스 문제집

관계대수 · SQL · DDL · ERD · 개념 확인을 쉬운 문제부터 단계별로 풀어 보는 문제집입니다. 파일 하나(`index.html`)로 동작하며 브라우저에서 열면 됩니다.

- **관계대수**: 식을 직접 입력하고 실행·채점 (자체 구현 엔진)
- **SQL / DDL**: 브라우저 안의 SQLite(sql.js)로 실행하고 결과·제약조건을 비교해 채점
- **ERD**: 도형으로 그리고 채점, ERD → 릴레이션/SQL 변환
- **개념 확인**: 선택·빈칸·서술형
- 풀이 기록과 "다시 볼 문제"는 브라우저(localStorage)에만 저장됩니다.

SQL 실행기는 CDN(cdnjs의 sql.js)에서 불러오므로 인터넷 연결이 필요합니다.
